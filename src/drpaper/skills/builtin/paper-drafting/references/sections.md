# 各节写作要点

## 摘要

四要素各占一句，顺序固定：

1. **问题**：研究对象与痛点，1 句（如"大语言模型在知识密集型任务中易产生幻觉"）
2. **方法**：本文做了什么、怎么做的，1~2 句，写具体机制不写空话
3. **结果**：核心发现或预期效果，1 句；无真实数据时写"实验结果表明该方法在……上优于基线"并标注【待补充】
4. **意义**：研究价值与应用前景，1 句

避免：第一人称"我们"泛滥、出现引用编号、出现图表引用。

## 关键词

- 3~5 个，从具体到一般排列（如"检索增强生成；大语言模型；幻觉缓解"）
- 用领域通用术语，不造新词；与题目不完全重复

## 1 引言

三段式漏斗结构，从宽到窄：

1. **背景与意义**（1 段）：领域重要性 + 存在的核心矛盾，结尾自然引出研究问题
2. **现有方法不足**（1 段）：概括主流路线及其局限，为本文动机铺垫；此处引用 2~3 篇文献
3. **本文工作**（1 段）："为此，本文提出……"，列 2~3 条贡献，末句概述全文结构

## 2 相关工作

- **按主题归纳，不按论文罗列**：把文献分成 2~4 条技术路线，每条路线一段
- 每段结构：路线概述 → 代表工作（引用）→ 该路线的局限
- 结尾用 2~3 句总结研究空白，与引言的"本文工作"呼应
- 引用密度最高的章节，检索到的文献应在此充分引用

## 3 方法

- **先总体后局部**：第一段给出框架全貌（可用"整体分为 X、Y、Z 三个模块"），再逐模块展开
- 每个模块：输入 → 处理机制 → 输出，说清数据如何流动
- 术语首次出现附英文原词；关键设计选择要给理由（"之所以采用 X 是因为……"）
- 方法名要贯穿全文一致，摘要、引言、方法、结论中不换叫法

## 4 实验设计

- 四要素齐全：数据集、对比方法（基线）、评价指标、实验细节
- 基线至少含两类：经典方法 + 近期方法，说明选择理由
- 指标要与问题匹配：分类任务看准确率/F1，生成任务看 BLEU/ROUGE 或人工评测
- **结果用三线表呈现**：表题行紧贴表格上方，每个表格后必须有分析段；示例：

```markdown
表 1：各方法在数据集 X 上的性能对比

| 方法      | 准确率 | F1   |
| --------- | ------ | ---- |
| 基线 A    | 78.2   | 76.5 |
| 本文方法  | 84.6   | 83.1 |
```

- 分析段写法：先指出现象（哪行哪列的差异），再归因到方法机制（"这得益于第 3 节的某设计"），最后补边界条件（"值得注意的是，当……时"）；禁止复述表格数字而不解释
- 无真实数据处用"【待补充：……】"占位，单元格同样填【待补充】；详细设计规范见 experiment-design skill

## 5 结论与展望

- 第一段：逐条对应引言中的贡献，总结本文工作，不引入新信息
- 第二段：坦承 1~2 条局限（数据规模、泛化性等）
- 第三段：未来方向，与局限衔接，1~3 条即可
