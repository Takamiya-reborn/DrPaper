# 论文起草：结构与篇幅

## 工作流

1. 若文献库为空，先用 search_arxiv 从 2~4 个角度检索（研究主题、方法名、应用场景），确保引用有据可依。
2. 调用 begin_draft 提交题目、大纲与各节字数预算：按下方占比表把用户目标字数 N 分配到各节，全部节预算之和必须等于 N；"摘要"固定 200~300 字，"关键词"budget 填 0。
3. 逐节调用 submit_section；写各节前可按需加载 `references/sections.md` 查看该节写法要点，加载 `references/patterns.md` 查看该节可用的论证序列与句式骨架。
4. 全部节提交后调用 finish_draft 校验，通过后调用 export_docx 导出。

## 结构模板

```
# 论文题目（一行，简洁具体，含方法或结论关键词）
**摘要**：200~300 字
**关键词**：3~5 个，分号分隔
## 1 引言
## 2 相关工作
## 3 方法
## 4 实验设计
## 5 结论与展望
```

## 字数分配参考（按占比换算）

| 章节 | 占比 | 核心任务 |
|---|---|---|
| 摘要 | 200~300 字（不按占比） | 问题、方法、结果、意义四要素 |
| 关键词 | 3~5 个（budget 填 0） | — |
| 1 引言 | 20% | 背景 → 现有不足 → 本文工作 |
| 2 相关工作 | 20% | 按主题归纳文献，指出研究空白 |
| 3 方法 | 30% | 总体框架 + 各模块展开 |
| 4 实验设计 | 20% | 数据集、对比方法、评价指标 |
| 5 结论与展望 | 10% | 贡献总结、局限、未来方向 |

其余各节 budget = N × 占比（四舍五入取整），全部节预算之和等于 N。

## 撰写纪律

- 每一节先想清楚"这一节要让读者相信什么"，再动笔。
- 每段必须含至少一个具体要素（文献中的方法名/数据集/数字，或本课题的具体机制），无具体要素的段落重写。
- **数据表格化**：3 个以上并列数值的对比（基线对比、消融结果、多数据集多指标）必须用 Markdown 表格，禁止在段落里罗列数字；表题行写"表 N：标题"并紧贴表格首行上方，正文用"由表 N 可见"引用表格；表格后必须紧跟一段分析——数字背后的原因、与方法机制的关联，禁止只报数不分析。
- 无真实数据处一律用"【待补充：……】"占位，禁止编造数字；占位的对比数据同样表格化，单元格填【待补充】。
- 字数不足时必须自行扩写（补充机制细节、实例与文献综述深度）；超出预算时自行压缩（合并重复论述）后重新提交该节，禁止写完反问用户。
- 一次性完成全部分节后才允许调用 finish_draft；未全部提交时调用只会返回缺失节列表。
- 禁用表达："随着……的飞速发展""众所周知""不可否认""具有重要意义""起到至关重要的作用""受到广泛关注"；同类衔接词相邻段落不重复。
