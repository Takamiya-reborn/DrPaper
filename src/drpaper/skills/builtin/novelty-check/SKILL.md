# 课题查新：比对已有研究，防止重复研究

## 查新流程

1. **提炼核心主张**：把课题压缩成一个填空——"针对【问题 X】，采用【核心思路 Y】，在【场景/任务 Z】上【目标 W】"。四个槽位即查新维度。
2. **多角度检索**：对每个维度组合调用 search_literature（传 register=false，查新是咨询、结果不入文献库），至少 3 组查询：
   - 思路直查：核心方法名/技术词（如 "retrieval augmented generation hallucination"）
   - 问题+替代思路：同一问题换方法词，找竞争路线
   - 场景+问题：应用域限定词，找细分领域的先行者
3. **逐篇比对**：对检索结果按四槽位判断与课题的重合程度。

## 重合度分级

| 等级 | 判定标准 | 结论 |
|---|---|---|
| 高风险 | 问题 X、思路 Y 均相同，仅场景或数据不同 | 大概率判定为增量工作，需重构创新点 |
| 中风险 | 问题 X 相同、思路 Y 相近，但机制或场景 Z 有实质差异 | 可行，但引言必须显式对比并突出差异 |
| 低风险 | 仅问题或仅场景重叠，思路 Y 有明确区分度 | 安全，正常撰写即可 |
| 无直接重复 | 未检索到四槽位两项以上重合的工作 | 通过，但仍需引用最接近的工作 |

## 输出格式

```
## 查新结论：中风险

最接近的工作：
- 〈标题〉（2024）——问题相同，思路相近，但未考虑时效性（本文差异点）
- 〈标题〉（2023）——场景重叠，方法路线不同

差异化建议：
1. 把创新点收窄到检索结果未覆盖的槽位（如：动态知识更新机制）
2. 引言与相关工作必须引用并对比最接近的工作（按〈标题〉对应），主动划清边界
3. 若无法划清边界，考虑更换思路 Y 或增加独有场景约束
```

## 纪律

- 结论基于检索到的证据，检索不到不等于不存在——明确提示"建议再人工核查 Google Scholar"
- 每个风险判断必须落到具体文献〈标题〉，不做笼统断言
- 查新后若继续写作，用 register=true 重新检索把最接近的工作登记入库，再按编号纳入引言与相关工作的对比框架
