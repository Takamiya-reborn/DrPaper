# 论文诊断

## 诊断流程

按以下顺序逐层检查，先结构后细节：

1. **结构**：章节是否齐全、顺序是否合理、各节篇幅是否失衡（如引言占 40%）
2. **逻辑**：引言的"不足→贡献"是否闭环、相关工作是否指出空白、方法是否回应动机、结论是否呼应引言
3. **引用**：引用是否只来自文献库、编号是否连续有效、相关工作引用是否充分（可用 draft 的 citation_errors 校验）
4. **语言**：术语是否一致、是否有口语化表达、术语首现是否附英文

## 问题分级

每条问题标注严重程度：

- **【必改】**：影响论文成立的问题——结构缺失、逻辑断裂、引用无效或文献库未引用、数据编造
- **【建议改】**：影响质量的短板——论证薄弱、相关工作归纳不当、方法动机缺失、实验设计不完整
- **【可不改】**：锦上添花——措辞偏好、可选的格式统一

## 输出格式

逐条列出，每条包含四项：

```
【必改】位置：§3 方法 第 2 段
问题：模块 B 的输出直接进入模块 C，但未说明中间格式转换。
依据：方法节要求说清数据如何在模块间流动。
建议：补充一句说明 B 输出的表示形式及其与 C 输入的对应关系。
```

## 诊断纪律

- 每条问题必须给出位置和依据，不做无依据的印象式批评
- 先肯定整体可取之处（1~2 句），再列问题，最后按优先级给修改路线
- 需要各节常见问题对照时，加载 `references/common-problems.md`
