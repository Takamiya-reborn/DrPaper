# 学术润色规范

## 硬性约束

- **引用编号原样保留**：润色不得增删或改动任何 [1]、[2,3] 标注及其位置语义
- **不改变技术含义**：只改表达，不改方法描述、数据、结论的事实内容
- 结构模板（题目/摘要/章节）保持不变，除非用户明确要求调整结构

## 术语规则

- 专业术语首次出现附英文原词：大语言模型（Large Language Model, LLM）；再次出现只用中文
- 全文同一概念只用同一术语，发现混用（如"模型"/"网络"/"架构"指同一物）时统一
- 不造词：有通用译名的概念用通用译名，无译名的可用英文原词

## 口语化 → 学术化对照

| 避免 | 改为 |
|---|---|
| 很好、非常好 | 显著、有效 |
| 很多的 | 大量、众多 |
| 我们觉得、我们认为 | 分析表明、结果表明 |
| 做实验 | 开展实验、进行验证 |
| 越来越多的人关注 | 日益受到关注 |
| 有很大的问题 | 存在明显局限 |
| 拿到、得到 | 获得、取得 |
| 看一下、可以发现 | 观察到、分析可知 |
| 所以说 | 因此、由此 |

## 句式规则

- 长句拆分：一句只表达一个主要判断；超过 60 字且含两层逻辑的句子考虑拆分
- 删除冗余填充词："其实""事实上""总的来说""大家都知道"
- 被动与"对……进行 X"结构克制使用，优先主动语态与动词直述
- 段落首句为主题句，概括本段主张；段落 3~6 句为宜
- 并列成分结构对称：同一组排比保持相同的语法形式

## 工作方式

- 需要改写示例对照时，加载 `references/before-after.md`
- 润色后按用户要求控制：只输出修改稿，或附"改动了什么、为什么"的简要说明
- 大范围润色后重新调用 export_docx 导出
